# Artisan Brew Co. - Coffee & Restaurant Website Template

Website quán cà phê phong cách mộc mạc tối giản, menu điện tử và đặt mang về.

## Hướng dẫn sử dụng:
1. Mở file `index.html` trực tiếp trên trình duyệt.
2. Để chạy máy chủ cục bộ:
   ```bash
   npx serve .
   ```
3. Deploy miễn phí:
   - Kéo thả thư mục vào [Netlify Drop](https://app.netlify.com/drop) để có ngay website online.
