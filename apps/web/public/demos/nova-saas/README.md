# NovaLaunch - SaaS Landing Page Template

Landing page chuẩn hiện đại dành cho Startup, Phần mềm, Khóa học và Micro-SaaS.

## Hướng dẫn sử dụng:
1. Mở file `index.html` trực tiếp trên trình duyệt để kiểm tra giao diện.
2. Để chạy máy chủ cục bộ:
   ```bash
   npx serve .
   ```
3. Deploy miễn phí:
   - Kéo thả thư mục vào [Netlify](https://app.netlify.com/drop) hoặc Cloudflare Pages.
