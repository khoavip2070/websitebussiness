# Aura Spa & Clinic - Website Template

Website hoàn thiện dành riêng cho Spa, Thẩm mỹ viện, Phòng khám chăm sóc sắc đẹp.

## Hướng dẫn sử dụng:
1. Mở file `index.html` trực tiếp trên trình duyệt (Chrome, Safari, Edge) để xem và chỉnh sửa.
2. Để chạy máy chủ cục bộ:
   ```bash
   npx serve .
   ```
3. Deploy lên mạng miễn phí:
   - Kéo thả toàn bộ thư mục này vào [Netlify Drop](https://app.netlify.com/drop) hoặc Vercel để có link website chạy trực tiếp trong 30 giây!
